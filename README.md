# 🎯 Freebet Arbitrage Calculator

Программа для расчёта оптимальных ставок при отыгрыше **фрибета** в букмекерской конторе по трём исходам события. Позволяет получить **максимально стабильный профит** независимо от того, какой исход выиграет.

> 💡 **Фрибет** — это бесплатная ставка от букмекера. Её выигрыш не включает возврат суммы ставки, поэтому для получения гарантированной прибыли нужно правильно распределить дополнительные ставки на другие исходы.

---

## ✨ Возможности

- Автоматический расчёт ставок на 2 дополнительных исхода.
- Балансировка выигрышей с точностью до ±15 ₽.
- Поддержка любых коэффициентов > 1.0.
- Удобный цветной интерфейс с пояснениями.
- Полностью на русском языке.

---

## ⚠️ Важно!

- **Арбитражные стратегии могут нарушать правила букмекерских контор.**  
  Некоторые БК могут ограничить или заблокировать ваш аккаунт при обнаружении подобной активности.
- Программа **не гарантирует прибыль** — она лишь находит математически выгодное распределение ставок при заданных коэффициентах.

## 📖 Как пользоваться программой

1. Введите **сумму фрибета** (например, `1000`)
2. Введите **коэффициенты на три исхода одного события**:

   * **1-й исход** — ставка фрибетом (ваши деньги не тратятся)
   * **2-й и 3-й исходы** — ставки за свои деньги
3. Все коэффициенты должны быть **строго больше 1.0**
4. Программа рассчитает:

   * оптимальные суммы ставок,
   * чистую прибыль при каждом исходе,
   * средний гарантированный профит
5. После расчёта:

   * `Enter` — выход
   * `1` — выполнить новый расчёт

❗ Программа работает **только с трёхисходными событиями**

## 🧠 Как работает алгоритм (кратко)

* Учитывается, что фрибет **не возвращает сумму ставки**
* Выполняется перебор возможных комбинаций ставок
* Для каждой комбинации проверяется:

  * неотрицательная прибыль по всем исходам
  * разница прибыли не превышает **±15 ₽**
* Из подходящих вариантов выбирается стратегия с **максимальным средним профитом**
* Перебор ограничен по итерациям для высокой скорости работы
